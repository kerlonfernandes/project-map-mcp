Features

Everything your AI agent needs to understand your codebase

Deterministic code analysis, evidence-backed knowledge, and progressive context delivery — all from a single MCP server.

Deterministic Parsing

PHP, JavaScript, Python, CSS and HTML parsed via Tree-sitter AST. Same input always produces the same output.

Knowledge with Evidence

Every assertion links to code, comments, docblocks, configs, or tests. 12 knowledge types with full validation lifecycle.

Progressive Context

4 depth levels and 5 purpose modes with token budgets. Returns exactly the amount of context your agent needs.

Dependency Graph

21 relationship types with weighted edges for impact analysis. Staleness propagation through BFS traversal.

Framework Detection

Laravel, Express.js, CoffeeCode and Plates adapters. Detects routes, models, middleware, events, migrations and more.

Portable Databases

Export and share your indexed project as a .pmap.db file. Teammates import it — zero re-analysis needed.

Full-Text Search

SQLite FTS5 across entities, knowledge records, and evidence. Structural and semantic search with ranked results.

Security by Default

Path traversal protection, blocked sensitive files, prepared statements only. Never executes project code.

Installation

Up and running in minutes

Follow these steps to install Project Map MCP on your machine.

Prerequisites: Node.js >= 18.0.0 • npm (comes with Node.js) • C++ build toolchain for native Tree-sitter bindings.

C++ Toolchain by OS:

OSCommand
Debian / Ubuntusudo apt install build-essential
macOSxcode-select --install
WindowsInstall Visual Studio Build Tools with "Desktop development with C++"

Clone the repository

Get the source code from GitHub.

bash
git clone https://github.com/kerlonfernandes/project-map-mcp.git
cd project-map-mcp

Install dependencies

This will compile native Tree-sitter bindings. The C++ toolchain is required for this step.

bash
npm install
Troubleshooting: If npm install fails with native module errors, make sure your C++ toolchain is installed (see table above) and try again. On Windows, run from a "Developer Command Prompt" or use npm install --build-from-source.

Build the project

Compile TypeScript to JavaScript in the dist/ directory.

bash
npm run build

Initialize a project (optional)

Point Project Map MCP to the codebase you want to analyze. This creates a .project-map/ directory with a SQLite database and a project-map.config.json configuration file.

bash
# Using the CLI (if installed globally or linked via npm)
pmap init /path/to/your/project

# Or using node directly
node dist/cli/index.js init /path/to/your/project

Run the first sync

Index the entire project. This parses all files with Tree-sitter and builds the knowledge graph.

bash
pmap sync --full

# Or using node directly
node dist/cli/index.js sync --full
What happens after init? A .project-map/ directory is created inside your target project containing the SQLite database (knowledge.db). A project-map.config.json file is placed at the project root with sensible defaults. You can customize it — see the Configuration section below.
Setup

Connect to your AI client

Configure Project Map MCP as an MCP server in your preferred IDE or AI assistant.

Automated setup available: Run ./setup.sh for interactive detection of installed clients, or ./setup.sh --client claude-desktop --project /path/to/project for a specific target. Works on macOS, Linux, and Windows (Git Bash / WSL).

Config file locations:

OSPath
macOS~/Library/Application Support/Claude/claude_desktop_config.json
Windows%APPDATA%\Claude\claude_desktop_config.json
Linux~/.config/Claude/claude_desktop_config.json
claude_desktop_config.json
{
  "mcpServers": {
    "project-map-mcp": {
      "command": "node",
      "args": ["/absolute/path/to/project-map-mcp/dist/index.js"],
      "env": {
        "PROJECT_MAP_PROJECT_ROOT": "/absolute/path/to/your/project"
      }
    }
  }
}
Important: Restart Claude Desktop after saving the config file. Both paths must be absolute.

Configuration

Customize behavior

Project Map MCP uses a project-map.config.json file at the project root. All settings have sensible defaults.

project-map.config.json
{
  "project": {
    "name": "my-project",
    "root": "."
  },
  "analysis": {
    "languages": ["php", "javascript", "python", "css", "html"],
    "frameworks": ["laravel", "express", "coffeecode", "plates"],
    "exclude_patterns": [
      "node_modules/**", "vendor/**", "dist/**",
      "build/**", ".git/**", "storage/**"
    ],
    "max_file_size_mb": 2,
    "max_directory_depth": 20,
    "max_files_per_sync": 500,
    "parse_timeout_ms": 30000
  },
  "database": {
    "path": ".project-map/knowledge.db",
    "max_size_mb": 500,
    "cache_size_mb": 64
  },
  "security": {
    "blocked_paths": [".env*", "*.pem", "*.key", "*.p12", "*.pfx"],
    "rate_limit": { "enabled": true, "max_per_minute": 60 }
  },
  "context": {
    "default_depth": "structure",
    "default_purpose": "understand",
    "default_token_budget": 2000,
    "max_token_budget": 200000
  }
}

CLI

Command-line interface

Common operations outside of MCP, using the pmap command.

bash
# Initialize a project
pmap init /path/to/project

# Incremental sync (only changed files)
pmap sync

# Full re-index
pmap sync --full

# Show project status
pmap status

# Search entities and knowledge
pmap search "PaymentService"

# Export database for sharing
pmap export "sprint-42"

# Import a shared database
pmap import /path/to/shared.pmap.db

# List available exports
pmap exports

# Help
pmap --help
Without global install: Replace pmap with node dist/cli/index.js to run any command directly.
Security

Security by default

All repository content is treated as untrusted data. Project Map MCP never executes your code and never calls external LLMs.

Path Traversal Protection

All file paths validated against project root. Symlinks escaping root are blocked.

Sensitive Files Blocked

.env*, *.pem, *.key, *.p12, *.pfx are never read. Configurable.

Prepared Statements Only

All SQL uses parameterized queries. Zero string interpolation.

Rate Limiting

Configurable per-minute limit (default: 60 req/min) to prevent abuse.

MySQL Safety

Connections restricted to allowed hosts. System schemas blocked. Read-only.

Full Audit Logging

Every tool call logged with parameters, results, entities affected, and duration.

Generic Error Responses

Internal details never leak to clients. Sensitive info stays server-side.

Deterministic Analysis

No LLM calls, no code execution. AST parsing only. Same input, same output.
